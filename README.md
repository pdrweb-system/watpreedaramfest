# แบบสำรวจการแสดงของนักเรียน
งานนมัสการปิดทองหลวงพ่อนิล วัดปรีดาราม (ยายส้ม) ประจำปี 2570

- **หน้าเว็บ:** GitHub Pages (`index.html` และ `config.js`)
- **ฐานข้อมูล:** Google Sheet
- **ไฟล์แนบ:** Google Drive
- **ตัวกลาง (API):** Google Apps Script (`apps-script/Code.gs`)

```
ผู้กรอก ──► GitHub Pages (index.html) ──fetch POST──► Apps Script (doPost) ──► Google Sheet / Google Drive
```

GitHub Pages เป็นเว็บแบบ static จึงเขียนข้อมูลลง Google Sheet หรือ Drive เองไม่ได้ ต้องใช้ Apps Script เป็นตัวกลางที่ทำงานด้วยบัญชี Google ของผู้ดูแล

## ข้อมูลในแบบฟอร์ม
1. ชื่อโรงเรียน
2. ชื่อผู้อำนวยการฝึกซ้อม
3. ระดับชั้น
4. ชื่อชุดการแสดง
5. ชื่อนักแสดง
6. ชื่อครูผู้ฝึกซ้อม
7. ลิงก์เพลง
8. อัปโหลดไฟล์ (ไม่บังคับ): สูงสุด 5 ไฟล์ ไฟล์ละไม่เกิน 100 MB

ไฟล์ใหญ่จะถูกแบ่งเป็นชิ้นละ 8 MB แล้วส่งทีละชิ้นผ่าน Apps Script เข้า Google Drive (resumable upload) เพราะ Apps Script รับข้อมูลได้ไม่เกินประมาณ 50 MB ต่อครั้ง

## หน้าสรุปข้อมูล
`summary.html` แสดงรายชื่อโรงเรียนที่ส่งการแสดงแล้ว เปิดได้จากปุ่ม "ข้อมูลโรงเรียนที่ส่งการแสดงแล้ว" บนหน้าแบบสำรวจ
- แสดงเฉพาะ ชื่อโรงเรียน ระดับชั้น ชื่อชุดการแสดง จำนวนนักแสดง และเวลาที่ส่ง
- **ไม่แสดง** ชื่อนักเรียน ชื่อครู ชื่อผู้อำนวยการ ลิงก์เพลง และไฟล์แนบ เพราะหน้านี้ทุกคนเปิดดูได้
- ดึงข้อมูลจาก Apps Script (`?action=list`) และเก็บ cache ไว้ 60 วินาที

## ติดตั้ง

### ขั้นที่ 1: ตั้งค่า Google Apps Script (API)
1. สร้าง Google Sheet ใหม่ แล้วไปที่เมนู **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิมใน `Code.gs` แล้ววางเนื้อหาจาก [`apps-script/Code.gs`](apps-script/Code.gs)
3. บันทึก เลือกฟังก์ชัน **setup** แล้วกด **เรียกใช้** จากนั้นกดอนุญาตสิทธิ์
   - ถ้าขึ้นว่า "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด **ขั้นสูง** แล้วเลือก **ไปที่ … (ไม่ปลอดภัย)**
   - ระบบจะสร้างชีต "คำตอบ" และโฟลเดอร์สำหรับเก็บไฟล์แนบใน Drive
4. ไปที่ **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่** แล้วตั้งค่าดังนี้
   - ประเภท: **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
5. คัดลอก **URL ของเว็บแอป** ซึ่งลงท้ายด้วย `/exec`

### ขั้นที่ 2: ใส่ URL ใน `config.js`
แก้ไฟล์ [`config.js`](config.js) ใส่ URL ที่ได้ใน `SCRIPT_URL` แล้วคอมมิตลง `main`
ระบบจะ deploy ขึ้น GitHub Pages ให้อัตโนมัติ

### ขั้นที่ 3: เปิดใช้ GitHub Pages (ทำครั้งเดียว)
ไปที่ **Settings → Pages → Build and deployment → Source** แล้วเลือก **GitHub Actions**
หน้าเว็บจะอยู่ที่ `https://pdrweb-system.github.io/watpreedaramfest/`

## หมายเหตุ
- Apps Script ต้องมีสิทธิ์ "เชื่อมต่อกับบริการภายนอก" (UrlFetchApp) เพื่อใช้ส่งไฟล์ขนาดใหญ่เข้า Drive ถ้าอัปเดตโค้ดจากเวอร์ชันเก่า ให้รัน **setup** อีกครั้งแล้วกดอนุญาตสิทธิ์ใหม่
- ถ้าอัปโหลดแล้วขึ้นข้อผิดพลาดว่า Drive API ยังไม่ได้เปิดใช้ ให้ไปที่ตัวแก้ไข Apps Script แล้วกด **บริการ (＋) → Drive API → เพิ่ม**
- พื้นที่ Google Drive ฟรีมี 15 GB ต่อบัญชี (ใช้ร่วมกับ Gmail และ Google Photos)
- ถ้าผู้กรอกอัปโหลดไฟล์แล้วปิดหน้าก่อนส่งแบบฟอร์ม ไฟล์จะยังอยู่ในโฟลเดอร์ Drive แต่จะไม่มีแถวคำตอบในชีต
- เมื่อแก้ `apps-script/Code.gs` ต้องนำไปวางในตัวแก้ไข Apps Script ใหม่ทุกครั้ง แล้วไปที่ **จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** เพื่อให้ URL เดิมยังใช้ได้
- ค่า `MAX_FILES`, `MAX_FILE_MB` และ `MAX_TOTAL_MB` ต้องตรงกันทั้งใน `config.js` และ `Code.gs`
- ไฟล์แนบใน Drive เป็นแบบส่วนตัว เปิดดูได้เฉพาะเจ้าของบัญชี
